AgriCheck — AI-Powered Soil Fertility Analyzer
AgriTech · Pakistan · IoT + Machine Learning + Agentic AI
The Problem
Pakistani smallholder farmers lack access to affordable soil testing. Fertilizer is applied by guesswork, leading to crop failure and wasted spend.
The Approach
Built an ESP32 device to read NPK, pH, and moisture via Modbus RS485 sensors. Trained a Scikit-learn classifier on the sensor data to prescribe the correct fertilizer blend. Added a LangChain + LangGraph RAG chatbot in Urdu and English for follow-up advice.
The Outcome
Full system deployed on Railway + Vercel. All 20 functional test cases passed — zero defects outstanding at submission. Bilingual support means the tool is accessible to farmers who don't read English.
